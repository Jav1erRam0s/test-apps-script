# BBDD_Tiempo_Real

Este repositorio muestra **en tiempo real** el estado de distintos **morrales** 🧳
La información se actualiza automáticamente y **puede modificarse directamente desde la página web** 🌐✍️

### 🔍 Estados posibles

* 🟢 **Completo**: el morral tiene todos sus elementos
* 🟡 **Incompleto**: le falta al menos un ítem
* 🔴 **No disponible**: no se puede usar ni asignar

### 🛠️ Funcionalidades

* ⏱️ Actualización en tiempo real
* 🖱️ Edición del estado desde la interfaz

### 🎯 Objetivo

Facilitar el **control, monitoreo y gestión** de morrales
